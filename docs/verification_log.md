# Verification log

Outcome of checking each `[knowledge]` item in the spec, plus environment findings. Everything here was observed on 2026-10-10 on an Apple M3 (8 cores), macOS (Darwin 25.6.0), Verilator 5.052, Apple clang 16.0.0, Homebrew LLVM 23.1.3, CMake 4.4.4, PicoRV32 `ef203c2`.

| ID | Item | Result | Evidence |
| --- | --- | --- | --- |
| V-01 | PicoRV32 defaults for multiply, divide, compressed, interrupts | **Confirmed.** Defaults are `ENABLE_MUL=0`, `ENABLE_FAST_MUL=0`, `ENABLE_DIV=0`, `COMPRESSED_ISA=0`, `ENABLE_IRQ=0`. **Exception:** `ENABLE_COUNTERS` and `ENABLE_COUNTERS64` default to **1**, so the wrapper sets them to 0. `CATCH_MISALIGN=1`, `CATCH_ILLINSN=1` by default. | `rtl/picorv32/picorv32.v` lines 62-88; wrapper `rtl/cutoff_core.v` |
| V-02 | Is the historical JALR low-bit issue fixed in the pinned core? | **Yes for the case tested.** `jalr x2, 0(x1)` with `x1 = 0x11` lands at `0x10`, link register is 8, skipped instruction did not run. This tests one odd-target case on the RTL, not the model (the model does not exist yet). | `Smoke.JalrClearsLowBitOfTarget` |
| V-03 | How to enable RVFI on the pinned core | **Partly answered.** RVFI ports exist in `picorv32.v` under ``ifdef RISCV_FORMAL`` (starting at line 123), and the core's Makefile builds with `-D RISCV_FORMAL`. Not yet exercised; the signal semantics and riscv-formal bindings are still to be read before checker C3 (Step 8). | `rtl/picorv32/picorv32.v`, `rtl/picorv32/Makefile` |
| V-04 | Can the register file be read from the Verilated model? | **Yes.** With `--public-flat-rw`, `rootp->cutoff_core__DOT__cpu__DOT__cpuregs[i]` reads register `i`. Used for the final-register check needed by checker C1. | `worker/sim_core.cpp`; `Smoke.AddProgramExitsWithSum` |
| V-05 | Verilator two-state behaviour and initialisation flags | **Pinned, and tested.** Built with `--x-initial 0 --x-assign 0`. Asking the runtime for random reset (`randReset(2)`, seed 12345) leaves the trace hash, cycle count and registers unchanged. This shows the flags work for the smoke program only; it is not a proof for every program. | `Smoke.RandomResetRequestDoesNotChangeTrace` |
| V-06 | Run-to-run determinism | **Observed.** Two separate `cutoff doctor` processes print the same trace hash; two in-process runs match. | `Smoke.TwoRunsGiveIdenticalTraces`; doctor output |
| V-07 | Sanitizers on this machine | **Apple clang's ASan aborts at startup** (`sanitizer_malloc_mac.inc:189 asan_init_is_running`), even on a one-line hello-world. Homebrew LLVM clang's ASan works. The `asan-macos` preset uses it. Cause not investigated. | Reproduced with a trivial program; 9/9 tests pass under `asan-macos` |
| V-08 | Build warnings | Cutoff's own sources: **0 warnings** under `-Wall -Wextra` in debug, release and `asan-macos`. One warning remains in the `asan-macos` configuration, from compiling GoogleTest's own library with LLVM 23 (`gtest-printers.h:528`, `-Wcharacter-conversion`). It is third-party code and is not suppressed. | Build logs |
| V-09 | Cycles per smoke program | The smoke program takes 38 cycles end to end with the 1-wait-cycle memory slave (D-005) and a 4-cycle trap window (D-011); it took 34 before D-011, the extra 4 are the window. Not a performance measurement. The trace hash `0xa822cf358b2c47ac` did not change. | `cutoff doctor` |
| V-10 | clang-tidy | `scripts/tidy.sh` is clean on all 5 Cutoff source files with the checks in `.clang-tidy`. One waiver: `popen` in `cli/doctor.cpp` (fixed literal commands only). | `scripts/tidy.sh build/debug` |

| V-11 | Alignment rule for jump targets without compressed instructions (spec `[knowledge]` item) | **Confirmed on the pinned core.** A taken branch, JAL or JALR whose target is not 4-byte aligned traps (offsets 2, 6, -2, 4094; JALR targets with bit 1 set after bit 0 is cleared). A branch that is not taken never traps. A JALR whose raw target has only bit 0 set (e.g. `0x1001`) goes to the even address and does not trap. | `ModelVsCore.MisalignedControlFlowTargets`: 18 programs, 0 differ |
| V-12 | **Bug found in my Step 1 testbench.** The core issues the bus request for a misaligned fetch or store one cycle before its `trap` output rises. The Step 1 harness ended the run on the bus event, so a misaligned store to the magic word reported `exited` and `jal x5,-2` reported `memfault`, while the model and the ISA say Trap. Fixed by D-011. Measured: with no wait `jal x5,-2` gives MemFault; from 1 cycle on it gives Trap; a legitimate exit followed by an illegal word stays Exited with a 64-cycle window. | `Smoke.TrapPreemptsABusEventEndingTheRun`, `Smoke.LongSettleWindowDoesNotTurnALegitimateExitIntoATrap`, `ModelVsCore.MagicStoreWidths` |
| V-13 | Model against hand-computed vectors | All unit vectors pass: every ALU, shift, compare, branch, jump, load and store at the boundary values INT_MIN, INT_MAX, -1, 0, 1, shift amounts 0, 1, 31 and 32 (low 5 bits), immediates -2048 and 2047, B and J extremes. Expected values were derived by hand from the spec; the encoder is checked against 26 known words (23 assembled by an independent Python script, plus `fence`, `ecall`, `ebreak`). | `Model*`, `Encoder*`, `Decoder*`, `Bits*` tests (34 of the 56 tests; 11 are smoke/doctor, 11 differential) |
| V-14 | Model against the Verilated core (directed differential) | **8,304 programs, 0 differences** in status, exit code and all 31 registers: 4,000 register-register, 1,320 register-immediate, 420 immediate shifts, 18 LUI/AUIPC, 2 x0 programs, 2,401 branch, 7 jump/link, 30 memory-lane, 12 magic-store-width, 76 trap/fault, 18 misaligned-target programs. This is a hand-chosen corner-case set, not the Step 4 baseline gate. | `ModelVsCore.*`; per-test counts printed by the suite |
| V-15 | Illegal and unsupported encodings | Core and model agree (all Trap) on 17 words: all-zero, all-ones, ECALL, EBREAK, CSR, MRET, RDCYCLE, MUL, compressed pattern, FENCE.I, and malformed funct3/funct7 variants. FENCE with three different field values runs as a no-op on both. | `ModelVsCore.TrapsAndFaults` |
| V-16 | Spike cross-check | **Not run.** Spike is not installed (spec marks it optional). Model correctness rests on the hand vectors plus agreement with the RTL. | `command -v spike` |
| V-17 | Coverage gaps of Step 2 | Not tested: self-modifying code (stores into the code region), the retire and store traces against the core (no tap yet), and programs longer than a few dozen instructions or with random operands (Step 4). | n/a |

| D-025 | 2026-10-11 | The stop rule compares **Q1/n** ("good-turing") with epsilon. Q1/n is the Good-Turing estimate of S31 Eq. 22 and what S32 calls the *coverage rate*: it estimates the expected number of new species in the next program and so upper-bounds the probability that the next program exhibits at least one. It is known to over-estimate (S32), i.e. to err towards running longer, not stopping early. S30's incidence-model formula **Q1/V** (Eq. 29) is reported in every checkpoint row but never used to stop: it answers a different question (the share of species occurrences that are singletons) and is smaller by V/n, the mean number of species per program (about 6.7 in the simulation, see V-32), so as a stop signal it would claim several times less risk than exists. S30's Eq. 28 (`coverage`) is selectable with `stop.estimator`. The dependency-aware estimator of S32 is not implemented; its full text was not read. Early on Q1/n exceeds 1; it is a rate there, not a probability, and the first useful checkpoints are the ones below 1. | Spec section 9 says "read the full source before implementing"; the sources define this quantity differently in the multinomial and incidence models. Resolved by reading S30 Section 7, S31 Section 4 and the S32 abstract, then checking numerically. |

| D-034 | 2026-10-11 | Dead logic is pruned by evaluating the parameters (defaults overridden by the `.NAME(number)` connections of `rtl/cutoff_core.v`): an `if`/conditional-generate/one-hot `case (1'b1)` branch whose condition folds to a constant is dead, as are `initial` blocks, the arm of a `?:` that its constant condition never selects, and any subtree that folds to a constant. | D-035 | 2026-10-11 | Operators (spec section 8 / S20 plus the domain additions): `+`/`-` swap; `==`/`!=` swap; each relational operator to the other three; `&&`/`||` swap; `&`, `|`, `^` each to the other two; drop or exchange `!` and `~`; integer constants to 0, 1, c+1, c-1; sized based constants to all zeros / all ones; signed/unsigned comparison (strip or add `$signed` on both operands); dropping a `$signed` outside a comparison (zero- instead of sign-extension); shift amount +1 / -1 when it is not a literal; stuck-at-0/1 of listed bits on every whole-signal assignment of the listed signals. | D-036 | 2026-10-11 | Instrumented form: every mutated expression E becomes `(mut_sel == 16'dK ? (mutation K of E) : ... : (E))`; `mut_sel` is a new 16-bit input of the core (0 = original design, 1..N = mutants in source order). Children are duplicated into each variant, so nested sites expand the text; generation fails if the file grows beyond 8 times its size (it grows far less here). Each mutant arm is made to agree with the signedness of the original expression (`$signed({1'b0, ...})` or `$unsigned(...)` around the arm), because a `?:` whose arms differ in signedness is unsigned as a whole and would silently change the original's sign extension (see V-41). | D-039 | 2026-10-11 | The *infected* bit of a mutant is computed at the root-expression level. The instrumented source gains, for every mutated root expression (the right-hand side of an assignment or the condition of an `if`), a shadow evaluation placed inside the original statement's own control flow: `inf_a` = the original value, `inf_b` = the value under mutant K, both widened to 64 bits, and `inf_K = (inf_a != inf_b)` is latched for the run. Because the shadow statements execute exactly when the original statement executes (a statement without `begin` is wrapped so it stays one statement; an `else if` chain is not broken), "infected" means: the statement owning the expression ran, and the mutation would have given that expression another value. Soundness argument: if no executed statement's expression differs under mutant K, the mutant's run is identical to the golden run, cycle for cycle. Continuous assignments get a `wire` pair and an `assign`. The infected port is one bit per mutant (bit 0 unused). | The spec's open item ("infected bit per site"); needs no extra simulation of the mutant to decide that it can be skipped. |

| D-041 | 2026-10-11 | Three funnel levels per (program, mutant): *infected* (D-039), *propagated* (the mutant run differs from the golden run in final registers, memory, status, exit code **or the untimed sequence of bus requests** (`bus_hash`: address, strobes and write data of every transfer, without cycle numbers or read data)), *detected* (checker C1 flags the mutant run against the reference model). | D-045 | 2026-10-11 | Drill mutation score: raw = killed / planted. Upper bound = killed / (planted - infected-not-propagated survivors), i.e. the score if every survivor that was infected but never changed a run were an equivalent mutant. No mutant is *proven* equivalent (that would need a formal tool; not in scope), so the upper bound is a bound under an assumption that is reported as such, and in this design it is known to be too generous: the sign-extension mutants of the J- and B-immediates are infected by every negative immediate of any instruction (the decoder computes all immediate formats for every instruction) but are only exposed by backward jumps, which G0 does not generate.
